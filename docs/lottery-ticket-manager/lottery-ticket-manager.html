儲存狀態

所有資料（期別、人員、摸彩券、目前期別設定）皆儲存在瀏覽器的 IndexedDB，不使用 localStorage。請固定用同一個瀏覽器、同一個檔案路徑開啟，並避免使用無痕模式或預覽視窗。
