📖 Zen Typewriter 使用手冊與指南

⌨️ 鍵盤快捷鍵一覽

快捷鍵 功能說明
Ctrl / Cmd + P開啟 / 關閉 Markdown 排版預覽視窗
Ctrl / Cmd + S手動立即儲存文稿至本機 IndexedDB
Ctrl / Cmd + E匯出當前文稿為 .md 檔案
Ctrl / Cmd + M快速開啟 / 關閉打字機敲擊音效（靜音）
Ctrl / Cmd + Shift + F切換段落聚焦模式（非當前段落半透明淡化）
F1 或 ?隨時喚起或關閉本使用手冊
Esc關閉開啟的彈窗，或喚起左側文稿庫抽屜

📝 Markdown 支援語法速查

  • # 標題一、## 標題二、### 標題三：階層標題
  • **粗體文字**、*斜體文字*、~~刪除線~~：文字強調
  • > 引言文字：經典打字機引文區塊
  • - 項目 或 1. 項目：清單項目
  • `code` 與 ```：行內代碼與多行程式碼區塊
  • | 欄位 | 欄位 |：表格語法（可在預覽視窗完整呈現）

✨ 核心特色功能介紹

  • 打字機視線置中 (Typewriter Scrolling)：鍵入與換行時畫面自動平滑捲動，讓游標與編輯行恆定保留在視野正中央，減輕頸部負擔。
  • 三款擬真音效合成：基於 Web Audio API 即時運算，提供復古金屬打字機（含換行回車鈴鐺聲）、段落青軸、輕音茶軸，完全無外部音效檔依賴。
  • 十款紙張色彩主題：包含羊皮古紙、抹茶茶室、深夜墨黑、水洗單寧等，切換即刻生效並記憶於瀏覽器。
  • 左右雙欄即時對照 (◫ 雙欄)：打字與排版結果並排展示，並支援一鍵複製編譯後的 HTML。

🔒 本地隱私與安全儲存

所有書寫草稿皆透過瀏覽器原生 IndexedDB 儲存於您的本機電腦中，不經過任何遠端伺服器，具備完整的私密性與離線可用性。
