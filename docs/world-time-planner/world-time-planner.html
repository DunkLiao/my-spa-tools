    匯入備份

    「合併」保留現有地點並覆蓋相同 ID；「取代」會先清空目前所有地點。

    怎麼用

    1. 在「我的地點」加入城市與時區，設定各自的上班時段。
    2. 用日期、基準時區與滑桿選擇時間；共識帶會標出每座城市的當地時間。
    3. 「最佳重疊時段」列出最多人同時上班的區間，點一下即可跳過去。
    4. 按「複製時間」把會議卡貼到訊息或行事曆邀請。
