# 公版離線型 SPA 網頁設計技術棧 (Offline SPA Architecture Stack)

本文件定義一套標準化、免伺服器、可離線獨立運行的「純前端單頁應用程式 (Client-Side SPA)」公版技術棧規格。僅規範技術選型與架構分層，不包含特定配色方案說明或具體程式碼實作細節。

---

## 1. 核心架構規範 (Core Architecture)

- **純用戶端單頁應用 (Pure Client-Side SPA)**：全部業務邏輯與渲染運算均在瀏覽器端完成，無需任何專用後端伺服器支援。
- **零構建與免打包機制 (Zero-Build Step)**：不依賴 Node.js、npm、Webpack、Vite 等前置編譯工具，保持代碼最簡透明度。
- **離線可用性 (Offline-First)**：檔案可直接由本機路徑（`file://` 協定）雙擊執行，亦可部署於任何靜態伺服器。

---

## 2. 基礎語言與標準 (Base Languages & Standards)

- **HTML5**：現代語意化標籤結構與無障礙網頁標準。
- **CSS3**：Flexbox / Grid 彈性佈局體系、CSS 變數（Custom Properties）與媒體查詢（Media Queries）。
- **Vanilla JavaScript (ECMAScript 6+)**：純原生 JavaScript 程式設計，無前端大框架（無 React、Vue、Angular）的維護負擔。

---

## 3. 介面與排版系統 (UI & Layout Framework)

- **Tailwind CSS**：實用優先（Utility-First）原子化 CSS 框架，負責高效結構佈局與控制項排版。
- **響應式佈局 (Responsive Web Design, RWD)**：支援桌機雙欄並排、平板自適應與手機端專屬分頁視圖切換機制。
- **雙主題切換引擎 (Dual Theme System)**：支援深色模式（Dark Mode）與淺色模式（Light Mode）無縫切換機制。

---

## 4. 排版與字型體系 (Typography System)

- **現代多語系無襯線字族 (Sans-Serif Font Stack)**：西文與繁體中文字體階層回退定義。
- **等寬代碼字型 (Monospace Font Stack)**：結構化資料與程式碼預覽專用字族。

---

## 5. 本機持久化存儲 (Client-Side Storage)

- **HTML5 IndexedDB API**：本機結構化物件資料庫，負責大容量資料持久化、狀態機存檔、版本快照與資料庫匯入/匯出/重設。
- **Web Storage API (`localStorage`)**：鍵值對輕量存儲，負責使用者介面偏好與主題狀態跨分頁記憶。

---

## 6. 離線檔案處理與交換 (File & Data Processing APIs)

- **Blob API & Object URL API**：於瀏覽器記憶體中動態生成二進制物件與下載管道。
- **FileReader API**：提供本機檔案選取、拖曳載入與即時內容讀取。
- **Asynchronous Clipboard API**：系統剪貼簿一鍵複製與非同步反饋。

---

## 7. 輕量資料轉換與壓縮套件 (Data Parsing & Packaging Libraries)

- **資料序列化與反序列化工具 (Data Serializer / Parser)**：結構化標記語言（如 YAML / JSON）之雙向轉換器。
- **本機檔案打包與壓縮工具 (Client-Side Archiver)**：多檔案即時打包與 ZIP 壓縮格式生成器。

---

## 8. 執行環境與相容性 (Runtime & Environment)

- **瀏覽器相容性**：支援所有現代主流瀏覽器（Google Chrome, Microsoft Edge, Mozilla Firefox, Apple Safari）。
- **託管相容性**：完全相容本機磁碟直接運行（`file://`）與各式靜態檔案託管環境（如 GitHub Pages、Cloudflare Pages、Vercel、S3、Nginx 等）。
