Bento Studio 使用與網頁套用指南

操作說明及將生成的便當盒排版嵌入到全新專案的完整步驟

1 工作室介面操作手冊

❖ 拖曳移動區塊

按住卡片右上角的雙橫線把手即可拖曳位置。藍色框表示可吸附，紅色框表示碰撞阻擋。

⤡ 自由縮放尺寸

滑鼠按住卡片右下角點狀拉伸把手拖拉，即可即時調整卡片的欄寬（Col Span）與列高（Row Span）。

🎨 樣式與自訂色彩

點選任一卡片後，左側面板提供 10 種精選高對比主題，亦可輸入 HEX 色碼（如 #6366f1）指定背景與字色。

2 如何套用至全新網頁專案（三步驟）

步驟 1 匯出代碼

排版滿意後，點擊右上角「匯出代碼」按鈕。建議選擇 Tailwind CSS (響應式) 或 原生 CSS Grid，點擊「一鍵複製代碼」。

步驟 2 黏貼至您的網頁中

若使用 Tailwind CSS 專案（例如 Next.js, Nuxt, Astro 或一般帶有 Tailwind CDN 的 HTML）：

<!-- 1. 如果是全新空白 HTML，可在 <head> 加入 Tailwind CDN -->
<script src="https://cdn.tailwindcss.com"></script>

<!-- 2. 直接在 <body> 中貼上剛複製的 Bento Grid 結構代碼 -->
<div class="grid grid-cols-1 md:grid-cols-4 gap-[16px] ...">
  <!-- 您的 Bento Cards -->
</div>

若使用 原生 CSS 模式：將 CSS 區塊貼入您的 style.css，並將 HTML 結構貼入對應頁面中即可。

步驟 3 將卡片換成真實組件與內容

產生的代碼已預先保留了乾淨的佈局骨架。您可以直接把卡片內的佔位文字替換為真實業務內容，例如： Chart.js 圖表、 產品截圖 <img>、 動態統計數值 或 CTA 行動呼籲按鈕。

響應式設計（Responsive Design）提示

匯出的代碼預設採用行動優先（Mobile-First）原則：在手機等窄螢幕裝置上（< 768px）會自動平鋪為易於上下滑動的單欄佈局 (1 Column)，在平板與桌機上才會展開為您所配置的 Bento 跨欄跨列排版，兼具視覺美感與最佳使用者體驗！
