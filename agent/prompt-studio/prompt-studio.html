            重點教學：如何定義與使用動態變數（Variables）
          

          

            在撰寫 Prompt 時，將重複性高或經常更換的受詞、品牌、受眾以雙大括號包覆，工作台會即時自動識別並抽出變數填空欄位，讓同一個提示詞模板能隨插即用。
          

          
          

            
📌 語法規則：

            
使用雙大括號包裹變數名稱，支援中文、英文與底線：

            

              {{產品名稱}}、{{targetAudience}}、{{user_role}}、{{預期效益}}
            

            

              💡 實例範例：「你是一位專精於 {{產業領域}} 的文案顧問，請為 {{品牌名稱}} 撰寫一封針對 {{目標受眾}} 的促銷郵件。」
            

          


          

            想直接體驗？點擊右側按鈕自動注入示範範本：
            
          

        


        
        

          

            
            結構化提示詞工程四部曲
          

          

            

              

                1
                挑選適合的框架
              

              

                點擊編輯區上方或左側「常用框架」選單（例如高精確度的 CO-STAR、任務導向的 RTF、或含範例的 CARE）。
              

            

            

              

                2
                模組化拆解填寫
              

              

                依據各區塊提示（情境、目標、受眾、格式規範）個別輸入，避免傳統單一大段落容易遺漏限制條件的缺點。
              

            

            

              

                3
                即時預覽與 Token 評估
              

              

                右側即時組裝標準 Markdown 語法，並提供總字數、Tokens 預估量及結構區塊統計，確保不會超出模型上下文上限。
              

            

            

              

                4
                版本控管與儲存
              

              

                點擊「儲存版本」將於 IndexedDB 自動記錄 v1.0、v2.0 快照，日後可透過下拉選單隨時無損還原任意歷史狀態。
              

            

          

        


        
        

          

            
            資料安全與 IndexedDB 本地儲存保證
          

          

            本工具所有專案、範本、自訂變數與歷史版本快照皆保存在您本地瀏覽器的 IndexedDB (PromptStudioDB)。完全不會將您的商業 Prompt 或機密內容上傳至任何雲端伺服器，離線亦可正常運作。
